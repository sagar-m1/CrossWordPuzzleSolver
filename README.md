# CrossWordPuzzleSolver
This project is a Python-based AI crossword solver that uses the Min-Conflicts heuristic with random restarts to fill crossword grids of sizes 3x3, 4x4, and 5x5. It automatically generates slots, assigns words from a dictionary, resolves conflicts through iterative improvement, and exports the solved grid with detailed statistics.

Features:

Supports 3x3, 4x4, and 5x5 crossword grids

Word dictionaries for 3, 4, and 5-letter words

Min-Conflicts algorithm with random restarts for efficient solving

Displays slots, intersections, iteration history, and statistics

Exports solved crossword to a text file

Tech Stack:

Python (random, time, os modules)

Algorithm: Min-Conflicts + Random Restart

Use Cases:

AI/ML demonstration of constraint satisfaction problems

Puzzle generation and solving

Academic projects showcasing heuristic search
